Impostor architecture map

A mobile-first web party game organized as a TypeScript pnpm monorepo: React/Vite in the browser, a Cloudflare Worker API at the edge, one Durable Object per room, and a shared domain package that owns game rules, snapshots, words, and scoring.

Data model and persistence

State stores

No standalone database service is present. Durable Object SQLite stores active room state; the browser stores room code/player id while auth uses an HttpOnly cookie; words and avatars are code-owned.

Architectural findings

Strengths, risks, and gaps

Findings distinguish observed facts from risks and recommended documentation work.

Strengths

  • Shared domain package centralizes game rules, state transitions, and scoring.
  • Durable Object gives each room a single authoritative writer.
  • Public/private snapshot boundary is explicit in domain code.
  • CI runs lint, typecheck, tests, and build on PRs and main pushes.

Coupling Hotspots

  • apps/web/src/lib/api.ts and apps/worker/src/protocol.ts duplicate realtime types.
  • apps/web/src/app.tsx holds many UI and orchestration concerns.
  • Production routing depends on Cloudflare Pages and Worker route alignment.

Missing Docs

  • Realtime protocol reference.
  • Security notes for room cookies, tokens, CORS, and snapshot privacy.
  • Worker integration test strategy.
  • Operations checklist for Cloudflare secrets, routes, rollback, and token rotation.

Testing Gaps

  • Domain tests are strong for rules and scoring.
  • Visible Worker tests focus on token signing.
  • Direct Durable Object tests for sockets, persistence, CORS, and alarms were not found.

Configuration Risks

  • TOKEN_SECRET must be set in production.
  • WebSocket auth now uses a room-scoped HttpOnly cookie.
  • VITE_API_BASE_URL is optional but important for split-origin deployments.

Ownership Boundaries

  • Web owns browser UX and local session state.
  • Worker owns public API ingress.
  • Room Durable Object owns authoritative room mutation and private snapshots.
  • Domain owns pure game rules and data contracts.
